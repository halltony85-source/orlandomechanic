# Orlando's Finest Mobile Mechanic — site rebuild

Rebuild of **orlandosfinestmobilemechanics.com** (live Wix two-pager) as a static
site generated by one Python file. Clickflame playbook: preserved slugs, real
service + city pages, full JSON-LD, humans.txt, Netlify-ready.

## Build

```
py -3.12 build.py
```

Output goes to `site/` (32 pages + style.css, main.js, humans.txt, robots.txt,
sitemap.xml). `netlify.toml` at the repo root publishes `site/`.

## What the old site had (captured 2026-08-20)

- Home page (`/`) — one-pager, no service pages, no schema, "HERE'S WHAT WE
  OFFER" heading with **no actual service list** under it.
- `/contact-us` — still carried **unedited Wix template filler for "House of
  Horsepower"**, a Clearwater luxury-car showroom, including a wrong phone
  number (859-539-6903). Rebuilt as a real contact page.

## Photos

`wix-assets/` (gitignored) holds all 9 originals pulled from the Wix site;
`prep_images.py` produces the optimized `assets/` set that `build.py` copies to
`site/img/`. Real assets used: the logo, an under-hood shot, a steering-column
shot, and a driveway Land Rover job — **cropped to remove a van branded
"Tampa Bay's Finest Mobile Mechanic, 813 530-6727"**. That branding (also on a
two-van photo we did NOT use) indicates the Orlando business is an expansion of
a Tampa sister company. The four remaining originals are Wix stock renders
(black sports cars, red leather seat) — intentionally unused.
